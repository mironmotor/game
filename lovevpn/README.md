# Love VPN — Telegram-бот @lovemevpn_bot + лендинг

VPN-сервис, который продаётся и обслуживается внутри Telegram: оплата, выдача
ключа, продление и реферальная программа — всё в боте. App Store не нужен
(оттуда VPN-приложения в РФ удаляют), сайт работает как витрина и ведёт в бота.

```
lovevpn/
├── bot/            Telegram-бот (Python 3 + aiogram 3)
├── web/            лендинг Love VPN (автономный HTML, без сборки)
├── deploy/         systemd-сервис и установщик для VPS
├── .env.example    пример настроек
└── README.md
```

## Быстрый старт (локально, на Маке)

```bash
cd lovevpn

# 1. Зависимости
python3 -m venv .venv
.venv/bin/pip install -r bot/requirements.txt

# 2. Настройки
cp .env.example .env
# откройте .env и впишите BOT_TOKEN (от @BotFather) и LOVEVPN_ADMIN_IDS (ваш ID)

# 3. Конфиги VPN — по одному в строке
#    (можно и позже: прислать .txt файлом прямо в бота от админа)
cp /путь/к/вашим/конфигам.txt configs.txt

# 4. Запуск
.venv/bin/python -m bot.main
```

Бот стартует на long polling — откройте `@lovemevpn_bot` в Telegram и нажмите
«Старт».

> **Токен бота — это пароль от бота.** Не вставляйте его в чаты, не коммитьте,
> не присылайте в переписке. Файл `.env` уже в `.gitignore`. Если токен всё-таки
> утёк — немедленно `/revoke` в @BotFather и впишите новый.

## Проверка логики без Telegram

```bash
python3 -m bot.smoke      # из каталога lovevpn/
```

Прогоняет на временной базе весь путь: регистрация по реферальной ссылке,
импорт конфигов, выдача ключа, пробный период, оплата, начисление бонусов обоим
и защита от повторного начисления. Зависимостей не требует — удобно запускать
после любой правки.

## Что умеет бот

**Для пользователя**

| Кнопка / команда | Что делает |
|---|---|
| `/start` | приветствие, главное меню, учёт реферальной ссылки |
| Купить доступ · `/buy` | тарифы и оплата звёздами Telegram |
| Мой ключ | статус подписки и выдача ключа |
| Пробный период | 3 дня бесплатно, один раз на аккаунт |
| Пригласить друга · `/ref` | личная ссылка, статистика, кнопка «Отправить другу» |
| Как подключиться · `/help` | инструкция и список приложений по платформам |
| `/status` | до какого числа действует подписка |

**Для админа** (только для ID из `LOVEVPN_ADMIN_IDS`; остальным эти команды не отвечают)

| Команда | Что делает |
|---|---|
| `/stats` | пользователи, активные подписки, оплаты, остаток ключей |
| `/grant <tg_id> <дней>` | начислить дни вручную (возврат, компенсация, тест) |
| `/revoke <tg_id>` | вернуть ключ пользователя в пул |
| `/addkeys` | прислать `.txt` с конфигами — бот импортирует их в пул |
| `/importfile` | импорт из `configs.txt` рядом с ботом |
| `/remind` | разослать напоминания тем, у кого подписка на исходе |

## Как устроена реферальная программа

Ссылка вида `https://t.me/lovemevpn_bot?start=ref_<ваш_id>`. При первом `/start`
приглашённый привязывается к пригласившему. После **первой оплаты** приглашённого
оба получают +30 дней.

Защита от накрутки: бонус только после оплаты, только один раз за каждого
приглашённого (гарантируется `UNIQUE(invited_id)` в таблице `referrals`),
самореферал отбрасывается, привязка фиксируется только при первом заходе —
«переприкрепиться» к другому пригласившему нельзя.

## Оплата

Сейчас — **Telegram Stars** (`currency: XTR`): не нужны юрлицо, договор с
платёжным провайдером и данные карт. Суммы в звёздах задаются в `.env`
(`LOVEVPN_STARS_M1/M6/M12`), потому что курс звезды к рублю не фиксирован —
сверьтесь с актуальным перед запуском продаж. Рублёвые цены (199 / 555 / 999 ₽)
лежат в `bot/config.py`.

Чтобы добавить ЮKassa или крипту, достаточно написать вторую функцию отправки
инвойса в `bot/payments.py` — обработчик `successful_payment` и логика подписки
не меняются.

## Откуда берутся ключи

Пул готовых конфигов в таблице `vpn_keys`: одна строка — один конфиг
(`vless://`, `ss://`, `vmess://`, `trojan://`, `hysteria2://`). Бот выдаёт
первый свободный и закрепляет за пользователем — при продлении ключ остаётся
тем же, заново настраивать приложение не нужно.

Если позже захотите выдавать ключи через панель (3x-ui / Marzban / Outline),
замените класс `KeyPool` в `bot/keys.py` на свой с теми же методами
(`import_lines`, `issue`, `release`, счётчики) — остальной код о происхождении
ключей ничего не знает.

## Деплой на сервер (24/7)

Бот должен работать постоянно, поэтому Мак не подходит — нужен VPS (можно тот
же, где стоит VPN).

```bash
# на Маке: залить папку на сервер
scp -r lovevpn root@ВАШ_СЕРВЕР:/root/

# на сервере
cd /root/lovevpn
sudo bash deploy/install.sh
```

Установщик создаёт системного пользователя `lovevpn`, кладёт код в
`/opt/lovevpn`, ставит зависимости в venv, включает systemd-сервис и запускает
его. Базу и конфиги держит в `/var/lib/lovevpn`, `.env` — с правами `600`.
Повторный запуск скрипта обновляет код и перезапускает бота.

```bash
journalctl -u lovevpn-bot -f      # логи
systemctl restart lovevpn-bot     # перезапуск
systemctl status lovevpn-bot      # состояние
```

Напоминания об истечении подписки шлются командой `/remind` — чтобы они уходили
сами, добавьте в cron ежедневный вызов или расширьте бота планировщиком.

## Лендинг

`web/index.html` — автономная страница: ни одного внешнего запроса, шрифты
системные, логотип встроен. Проверено рендером в обоих размерах — горизонтального
скролла нет.

Выложить можно куда угодно (Vercel, Netlify, GitHub Pages, nginx на том же VPS):
это просто статика. Все ссылки CTA ведут в `@lovemevpn_bot`.

**Перекраска бренда**: правьте блок `:root` в начале `index.html` и в
`web/design-system.css` — полупрозрачные оттенки заданы отдельными переменными
(`--accent-soft`, `--accent-line`, `--accent-glow`), поэтому смена `--accent` не
оставляет старых цветов. Логотип — `web/logo.svg` (сердце в щите), он же favicon
и продублирован инлайном в шапке и герой-блоке.

`web/design-system.css` подключайте на остальные страницы, если появятся —
там готовые `.btn`, `.card`, `.panel`, `.input`, `.badge`.

## Что стоит добавить дальше

- Автоматические напоминания по расписанию (cron или планировщик внутри бота).
- Возврат звёзд через `refundStarPayment` для спорных оплат.
- Отключение ключа по истечении подписки — сейчас ключ остаётся у пользователя
  до `/revoke`. Автоотключение требует панели с API (см. раздел про ключи).
