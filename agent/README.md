# Ночной агент MAX

Claude Agent SDK на маке: смотрит логи живого mir.care, докладывает в Telegram,
код правит только с предупреждением. Сервер не трогает — выкат остаётся ручным.

## Запуск

```bash
export PATH="$HOME/.local/nodejs/bin:$PATH"
cd ~/game-ultra/agent

node night.mjs                    # обход-наблюдение: только смотрит и докладывает
node night.mjs --fix              # плюс правит код в рабочей копии (каждый файл анонсирует)
node night.mjs --task "почини X"  # разовое задание
```

## Предупреждения в Telegram

Токен бота живёт только на дроплете, поэтому сообщения отправляет он сам:

```bash
npm run install-notifier          # разово кладёт /root/max-agent-notify.sh на дроплет
export MAX_AGENT_TG_CHAT=<chat_id владельца>
```

Без `MAX_AGENT_TG_CHAT` предупреждения идут только в консоль и журнал
(`~/.local/max17/agent-journal.log`), а режим `--fix` не стартует вовсе: агент с
правом записи, который не смог предупредить, опаснее, чем отсутствие агента.

## Что ему нельзя

| Запрещено всегда | Почему |
|---|---|
| ssh, rsync, pm2, деплой | сервер меняет человек |
| `.env*` | ключи |
| `mark17/state/` | живая память ядра, её нет в git |
| `git push/commit/reset/checkout` | история — не его дело |
| Bash вне белого списка читающих команд | цепочка безопасна настолько, насколько безопасно худшее звено |

Правки файлов возможны только с `--fix`, только внутри `~/game-ultra` и только
после отправленного предупреждения.

## Постоянный цикл руки

```bash
node loop.mjs                     # тик раз в 90 с; молчит, пока ядру ничего не нужно
cp com.max17.hands-loop.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.max17.hands-loop.plist
```

Холостой тик — одна ssh-команда («сколько заявок у ядра») и **ноль токенов**.
Модель просыпается, только когда MAX действительно попросил. Предохранители:
пауза между прогонами (`MAX_LOOP_COOLDOWN_SEC`, по умолчанию 120 с), потолок
`MAX_LOOP_DAILY_RUNS` (40) на сутки и запрет параллельных прогонов.

Рука не ходит по ssh сама — её Bash ограничен белым списком читающих команд. Но
показания приборов сервера (диск, память, процессы, ответ сайта) собирает
`collect.mjs` и подмешивает в задание: смотреть можно, дотянуться руками нет.

## По расписанию

```bash
cp com.max17.night-agent.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.max17.night-agent.plist   # 03:30 каждую ночь
```

Ночью работает режим наблюдения. Правки — когда человек сам запустит `--fix`.

## Очередь от ядра

MAX (или админка) дописывает строки в `~/.local/max17/agent-queue.jsonl`:

```json
{"task": "в чате пропадает последний ответ, посмотри роут max17"}
```

Ближайший обход заберёт очередь, разберёт задачи и очистит файл.

## Деньги

Каждый прогон печатает стоимость и пишет её в отчёт (`agent/reports/`).
Потолок — `MAX_AGENT_BUDGET_USD` (по умолчанию $2), ходы — `MAX_AGENT_MAX_TURNS` (40).
