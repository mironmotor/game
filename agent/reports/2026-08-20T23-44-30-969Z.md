## Ночной обход — топ-5 находок

**1. Race condition на файле состояния LLM** (`mark17/llm_config.py:214-228`) — критично
`_read_state()` и `_write_state()` работают с `mark17/state/llm_active.json` без блокировки. Два одновременных HTTP-запроса к `/api/llm-config` (переключение модели + фоновый опрос) могут перезаписать друг друга. Потеря выбранной модели, откат к дефолту — незаметно для пользователя. Предложение: `fcntl.flock()` вокруг read/write пары.

**2. SQLite без WAL в кэше эмбеддингов** (`mark17/embedder.py:199-202, 253-254`) — высокое
`neural_embed()` и `routing_embed()` пишут в одну SQLite БД без синхронизации. При параллельных ingest-запросах возможно `database is locked`, и эмбеддинг падает молча (исключение поглощается). Предложение: `PRAGMA journal_mode=WAL` при открытии соединения.

**3. Валидация premium-кода отсутствует** (`lib/max17-client.ts` функция `readPremiumCode`) — среднее
Любое значение из `localStorage['premiumCode']` уходит на сервер без проверки формата. Если клиентский JS скомпрометирован (XSS через будущий markdown/paste), атакующий может подменить значение. Предложение: валидировать формат (UUID/hex, ≤64 символа) перед отправкой.

**4. guard() — best-effort защита** (`agent/night.mjs:42-48`) — среднее, актуально при `--fix`
Regex `/\bssh\b/` ловит прямые вызовы, но `bash -c "ss""h user@host"` или `python -c "import subprocess; subprocess.run(['ssh',...])"` пройдут. В режиме наблюдения (`plan`) это неважно — Bash всё равно в plan-режиме. Но при `--fix` риск реален. Предложение: перейти на whitelist (`git diff`, `grep`, `cat` и т.п.) вместо blacklist.

**5. WebGL context loss без dispose** (`components/hud/HudGround.tsx:887-891`) — низкое
При потере контекста (`webglcontextlost`) отменяем только `requestAnimationFrame`, но не вызываем `renderer.dispose()`. При восстановлении контекста (`webglcontextrestored`) и повторном mount компонента текстуры и геометрии не освобождаются — постепенный memory leak на мобилках и старых Mac. Предложение: в обработчике `contextlost` вызвать `renderer.dispose()` и выставить флаг для полного переинита.
