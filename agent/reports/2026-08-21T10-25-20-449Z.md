## Аудит кода ветки ultra

### Топ-5 по важности

**1. `app/api/llm-config/route.ts` — зомби-процессы при таймауте**
Признак: `child.kill('SIGTERM')` без закрытия потоков (`stdout`/`stderr`/`stdin`).
Причина: обработчики событий висят, процессы накапливаются при медленном старте Python.
Предложение: после `kill` добавить `child.stdio.forEach(s => s?.destroy())`.

**2. `lib/max17-client.ts` — `localStorage` падает с `SecurityError`**
Признак: `localStorage.getItem(...)` вызывается без try/catch, только с `typeof window` проверкой.
Причина: в sandbox-iframe или privacy-режиме этого недостаточно — бросает исключение.
Предложение: обернуть в `try { ... } catch { return null }`.

**3. `mark17/embedder.py` — глобальное SQLite-соединение никогда не закрывается**
Признак: `_cache_conn` инициализируется один раз, `atexit`-хендлера нет.
Причина: при долгой работе в daemon-режиме накапливается блокировка WAL.
Предложение: добавить `atexit.register(lambda: _cache_conn and _cache_conn.close())`.

**4. `components/hud/AppearancePanel.tsx` — утечка Object URL**
Признак: `wavUrl` используется в `useEffect`-cleanup, но не в списке зависимостей (`[]`).
Причина: заглушен eslint, поэтому не видно предупреждения. Старый URL не ревокается.
Предложение: заменить зависимость `[]` на `[wavUrl]`.

**5. `components/hud/HudGround.tsx` — `pointermove`/`pointerleave` на window без гарантии очистки**
Признак: слушатели вешаются на `window`, cleanup есть, но если размонтирование асинхронное (Suspense), они успевают стрельнуть по уже уничтоженным WebGL-ресурсам.
Причина: Three.js объекты диспозируются раньше, чем React снимает listeners.
Предложение: добавить `AbortController` или флаг `disposed` перед диспатчем в колбэке.
