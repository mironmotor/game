# Функции продукта (UI)

Что реально внедрено и доступно пользователю в `/game`.

## Совет Ангелов (`components/AngelsPanel.tsx`)
Адаптивная панель сверху (fixed-overlay), не мешает HUD. Вызов: бар сверху, кнопка **✨ Совет** в
доке HUD, или событие `angels:open`.

| Элемент | Что делает |
|---|---|
| Поле ввода + **Спросить** | прогон MAX + 7 агентов, мгновенный ответ |
| **⚡ Разгон** (бар и док) | контекстный «разгон дня»: строит миссию из твоих открытых задач, берёт топ в работу |
| **🧠 Глубже** | агенты рассуждают через реальную модель (Gonka), ~10с; бейдж «глубоко» |
| **🤖 Агент** (тумблер) | вкл → MAX берёт задачи Совета в работу (создаёт задачи игры, авто-старт №1, конвейер) |
| **🔊 Голос** (тумблер) | MAX озвучивает ответ (JARVIS-style, см. ниже) + пикер голоса |
| **×** | свернуть панель (вернуть — кнопкой «Совет» в доке) |

**Вывод**: миссия дня → карточки 7 ангелов (summary, инсайты, % уверенности; неподключённые
приглушены) → приоритетные действия → риски (Guardian) → рекомендация MAX. Карточка **Память**
показывает «MAX вспомнил» (реальные воспоминания).

**Взято в работу**: задачи попадают в систему игры (менеджер MGR-1/2/3, XP), синхронятся в
HUD-миссии (`game:tasks-sync`). У каждой задачи:
- **▶ Выполнить** — MAX разбивает на шаги; техзадача → реальный **architect-агент** (ветки+файлы).
- **🛠 Код** (техзадачи) — реальный **code-агент** пишет файлы в песочнице `code-workspace/`.
- **▶ Авто** — прогон всего плана по очереди через исполнителей.
- **Готово** — закрывает задачу (XP) и шлёт `outcome_success` (MAX учится); подхватывает следующую.

## Корпус → синапсы (`components/CorpusPanel.tsx`)
Пилюля **📚 Корпус** внизу справа — контролируемый канал кормления ядра.
- Режим **Текст**: вставляешь курируемый текст/заметки/данные → MAX компилит в структурные синапсы.
- Режим **Путь**: путь к файлу/папке проекта (текстовые форматы) → ингест разом. Заперто в каталоге проекта.
- Показывает `+X синапсов`, всего, фрагменты/кеш.
- **Дашборд роста**: спарклайн синапсов во времени + `всего / 1 000 000 · %` + прогресс-бар.
- Идемпотентно (кеш по хешу), офлайн. Это «правильный» путь к 1M (смысл, не веб-мусор).

## Голос MAX (JARVIS-style, `lib/jarvis-voice.ts`)
- Озвучка ответов через браузерный SpeechSynthesis. **Не клон актёра** (права/этика, офлайн
  невозможно) — JARVIS по манере: низкий, спокойный, размеренный тон (pitch ~0.8, rate ~0.97).
- Авто-выбор русского мужского голоса (macOS «Yuri», Windows «Pavel», иначе Google ru).
- **Пикер голоса** в баре (когда 🔊 включён): список реальных голосов системы + «Тест» (превью).
- Настройки сохраняются (localStorage: `max_voice`, `max_voice_name`).

## Визуал ядра (`components/hud/NeuralCore.tsx`)
WebGL-ядро (Three.js). Скорость анимации реагирует на статус: `processing` ×2.5, `speaking` ×1.5,
`listening` ×0.5. Теперь **ускоряется и от панели Совета** через событие `max:thinking`
(шлётся вокруг Спросить/Разгон/Глубже/Выполнить/Код).

## Чат с MAX (HUD)
Окно «ВЫВОД MAX17». Шлёт `user_message` в ядро. Намерение классифицируется:
- код/desktop-запрос (уверенность ≥0.6) → **диспатч в агента**: HUD открывает код/desktop-режим с
  задачей (а не печатает код текстом). Роутер понимает языки (java/джав, питон, ts…) и глаголы
  (сделай/напиши/набросай…).
- иначе → разговорный ответ (голос Gonka), с маршрутом/уверенностью в статусе.

## HUD «Game» (`components/hud/`)
Существующие модули HUD (поверх ядра): окна/доки (`window-manager`, `GameHud`, `HudWindow`),
миссии/задачи и XP (`use-game-state`), консоли агентов (`CodeConsole`, `ArchitectConsole`,
`DesktopConsole`), панель «Вид» (`AppearancePanel`: темы, фоны вкл. «Майами», генератор снов-обоев,
**Dreaming Music** из вкуса MAX), переключатель моделей (`ModelSwitcher`), камера/лицо
(`face-detect` + модели `public/models`), голосовая активация (`use-voice-wake`, `voice-signature`),
нейро-ядро (`NeuralCore`).
