## Обзор

**MAX** — это когнитивное ядро («ядро сознания») продукта. **Game** — геймифицированный
HUD-интерфейс поверх него. Вместе это система, которая помогает пользователю двигаться
к реальным результатам, а не залипать в переписке с ассистентом.

Технически продукт состоит из двух половин:

- **Next.js-приложение** (`app/`, `components/`, `lib/`, `hooks/`) — HUD «Game», панель
  «Совет Ангелов», панель «Корпус», чат с MAX. TypeScript, React 19, basePath `/game`.
- **Python-ядро `mark17`** (внутреннее имя «Max17») — память на графе синапсов, векторная
  память, обучение на исходах, концепты, голос (Gonka/Qwen3), web-sense. Общается с
  приложением через персистентный демон (`mark17/serve.py`) и one-shot мост (`mark17/json_cli.py`).

### Принцип продукта (из корня README)
> Каждый ответ MAX должен **увеличивать контакт пользователя с реальностью**, а не уменьшать его.
> Хорошие ответы толкают к действию: тело, работа, деньги, живые люди, созданный результат.
> Ответы, которые только держат пользователя в системе в ожидании «божественных ответов»,
> считаются провалом продукта.

Этот принцип закодирован в `mark17/principles.py` и используется детерминированным ответчиком.

### Путь к 1 000 000 синапсов
Главная долгосрочная цель ядра — **миллион ПОЛЕЗНЫХ синапсов** (не сырых данных).
«Полезные» = структурные связи из реального смысла, обучения и опыта, а не свалка из веба.

- Текущий счёт виден через `npm run max17:stats` или панель «Корпус» (дашборд роста).
- Растёт за счёт: ходов Совета, обучения на исходах, и **контролируемого ингеста корпуса**
  (панель «Корпус» → текст/файл → структурные синапсы). Подробно — в [02-max-core](02-max-core.md).

### Что внедрено за последнюю итерацию (кратко)
- **Совет Ангелов**: MAX-оркестратор + 7 агентов, берёт задачи в работу, конвейер исполнения.
- **Реальная память Max17** в Совете (быстрый `memory_recall`, чистая, персист ходов).
- **Цикл обучения**: исход задачи → ядро усиливает/ослабляет синапсы → планы умнеют.
- **Семантическая память**: онтология жизненных доменов, recall по смыслу.
- **Исполнители**: architect (ветки), **code-агент** (реально пишет файлы в песочнице).
- **Deep-режим**: агенты рассуждают через реальную модель (Gonka) + авто-эскалация при неуверенности.
- **Корпус-ингест** (текст и путь) + **дашборд роста графа** к 1M.
- **Голос MAX** (JARVIS-style, русский, с выбором голоса).
- **Визуал ядра** ускоряется, пока MAX думает.

Полный список с деталями — в [04-product-features](04-product-features.md).
