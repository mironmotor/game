# Эфир — голосовой контур Макса

**Эфир** — это живой канал между человеком и ядром Max17: микрофон снимает голос,
браузер считает акустику, ядро читает по ней состояние человека, а Макс отвечает
голосом. Контур офлайн-first: если мост Max17 недоступен, эфир всё равно работает —
состояние оценивается локально по тем же правилам.

## Из чего состоит эфир

| Слой | Где | Что делает |
| --- | --- | --- |
| Ввод голоса | `components/GameApp.tsx`, `components/hud/HudApp.tsx` | Web Speech API (распознавание), фолбэк «режим уха» на iOS |
| Звуковая сигнатура | `components/hud/VoiceSignature.tsx` | Считает акустику: тон `f0`, регистр, яркость, дрожание, энергию |
| Чтение состояния | `mark17/voice_state.py` | По акустике + персональной норме выводит возбуждение / позитив / напряжение |
| Событие ядра | `mark17/json_cli.py` (`voice_state`) | Пишет состояние в память и синапс-граф, связывает с контекстом разговора |
| Озвучка | `lib/gemini.ts` (`generateSpeech`) | Ответ Макса голосом через `speechSynthesis` |

Персональная норма («так этот человек звучит обычно») копится по EMA в
`voice_profiles.db`, поэтому один и тот же тон читается относительно конкретного
говорящего.

## Квантовые глаза — Макс видит сквозь эфир

`components/hud/QuantumEyes.tsx` даёт Максу **пару глаз в квантовом мире**. Глаза
подключены к тому же живому эфиру (акустика + состояние Max17) и отрисовываются как
поле вероятности. Весь движок держится на числе Эйлера **e = 2.718**:

| Формула на e = 2.718 | Что задаёт | Из эфира |
| --- | --- | --- |
| Гауссов волновой пакет `ψ(r) ∝ e^(−r²/2σ²)` | ширину зрачка σ (дыхание радужки) | **возбуждение** |
| Фаза Эйлера `e^(iθ) = cos θ + i·sin θ` | скорость мерцания интерференции радужки | **тон f0** |
| Туннельное затухание `α ∝ e^(−κ·d)` | мягкость и ширину внешнего свечения | **позитив** |
| Распад квантовой пены `α ∝ e^(−возраст/жизнь)` | время жизни виртуальных частиц | яркость / энергия |
| Коллапс волновой функции (веса `∝ e^(−d²)`) | куда «смотрит» взгляд после измерения | **энергия** (частота) + **напряжение** (разброс) |

Дополнительно: нить **запутанности** между зрачками декогерирует с ростом
напряжения; при тишине в эфире веки полуприкрываются — Макс дремлет.

Глаза открываются автоматически, когда эфир слушает: кнопка `◉` в HUD →
модалка «Квантовые глаза · Звуковая сигнатура · Max17».

## Эфир-реальность — 3D-космос из голоса (`/efir`)

`components/efir/EfirReality.tsx` — отдельный режим: голос не крутит готовое
облако, а **рождает материю**. Каждый озвученный кадр эфир выбрасывает частицы
в 3D-космос (число ∝ энергии, высота ∝ регистру). Тишина — эфир перестаёт
питаться, и материя испаряется. Чистый Canvas 2D со своим проектором 3D→2D
(yaw/pitch + перспектива, как в `Attractor.tsx`), без внешних зависимостей.

Мир целиком построен на **e = 2.718**:

| Закон на e = 2.718 | Что задаёт | Из эфира |
| --- | --- | --- |
| Логарифмическая спираль `r = r₀·e^(b·θ)` | рукава галактики (θ = ln(r/r₀)/b) | **напряжение** → закрученность b и число рукавов |
| Экспоненциальный распад `яркость ∝ e^(−t/τ)` | жизнь и смерть частицы | **позитив** → долгота жизни τ |
| Экранированная гравитация `F ∝ e^(−κ·d)` | стяг к ядру Макса | **возбуждение** → κ |
| Атмосферная дымка `α ∝ e^(−z/d)` | глубина: дальнее тускнеет | ось Z |
| Фаза Эйлера `e^(iθ)` | орбитальное вращение | **тон f0** |

Микрофон общий с квантовыми глазами — оба питаются из хука
`hooks/use-efir-signal.ts` через единый `signalRef`. Глаза можно посадить в угол
космоса (кнопка `◉`), и они смотрят за своей же реальностью. Открывается из меню
режимов (`△∞ Эфир · реальность из голоса`).

## Ядро MAX VISION — визуализация звука (`/vision`)

`components/vision/MaxVision.tsx` — визуализатор звука через эфир в духе
TouchDesigner: жидкое чернильное цветение. Спектр голоса (лог-разнесённые полосы
по `ln f`) раскладывается **радиально в цветок** — каждая частотная полоса
рождает поток частиц в свою сторону. Частицы текут по curl-полю, аддитивно
светятся и оставляют следы; обратная связь (feedback-zoom) размазывает кадр,
давая текучий дым. Палитра синь→фиолет→розовый→белое.

Опоры на **e = 2.718** и слух:
- спектр по `ln f` — полосы разнесены логарифмически, как в слухе;
- затухание следа частицы `свет ∝ e^(−t/τ)`;
- бас раздувает ядро-свечение `R ∝ e^(bass)`, верх крутит и турбулит поле.

Полный FFT-спектр отдаёт общий хук эфира: `useEfirSignal` пишет
`VISION_BANDS` (96) сглаженных полос в `spectrumRef`, который читают и большое
полотно, и спектр-лента снизу. Веди пальцем по холсту — рисуешь светом.
Открывается из меню режимов (`△∞ MAX VISION`).

## World Model — у ядра появляется информация о 3D-мире

`mark17/world_model.py` — первая точка, где Max17 узнаёт, что рисуется в
браузере. До него поток был односторонним: эфир → браузер рисует → всё гаснет
вместе с вкладкой, и ядро не знало о мире ни одного бита.

**Перепись.** Браузер шлёт не частицы (их десятки тысяч), а сводку из двух
десятков чисел раз в секунду — событие `world_state`: сколько живых, сколько
родилось и погасло, радиус и плотность облака, закрутка `b`, рукава,
доминирующий оттенок, симметрия.

**Семя.** Мир — это `(seed, лента переписей)`, а не сессия. Адрес выводится из
семени детерминированно (`w-…`), поэтому мир открывается тем же завтра.
Семенем может быть слово: `seed: "мир-о-музыке"`.

**Вещество.** Частицы гаснут по `e^(−t/τ)` и сами не оставляют ничего. Мир
начинается там, где часть перестаёт гаснуть — и ответ, почему что-то остаётся,
в ядре уже был: `critic` аннигилирует пары оценок, `genesis.baryon_asymmetry`
считает перевес выживших, `genesis.nucleate` говорит, какая доля связалась при
нынешней температуре. Рождения за интервал считаются парами, гашения —
аннигиляциями. Связавшееся вещество пишется в `world_model.db` и переживает
перезагрузку страницы.

**Законы.** Обратно ядро отвечает не текстом, а физикой следующего интервала —
из эфира `genesis`: `c = 1/sqrt(eps·mu)` и импеданс `Z = sqrt(mu/eps)`.
Плотность мира загущает среду как нагрузка, напряжение человека из
`voice_state` — как неуверенность. Отсюда:

| Закон ядра | Что делает в мире |
| --- | --- |
| `emission_scale` ~ 1/Z | цена рождения материи: густой эфир — скупой мир |
| `lifetime_scale` ~ Z | густая среда дольше удерживает рождённое |
| `bound_fraction` | способен ли мир вообще держать структуру |
| эпоха и температура | что может сконденсироваться прямо сейчас |

Проверка: `python3 mark17/test_world_model.py`.

## Событие `voice_state`

Пример payload (`mark17/examples/max17-voice-state.json`):

```json
{
  "type": "voice_state",
  "user_id": "miron",
  "context": "опять не работает, бесит",
  "acoustics": { "f0": 150, "register": 0.55, "brightness": 0.7, "jitter": 0.35, "energy": 0.8, "voiced": true }
}
```

Ответ ядра содержит `voice.{arousal, valence, tension, label, note, baseline}` —
ровно те поля, которыми питаются и телеметрия сигнатуры, и квантовые глаза.
