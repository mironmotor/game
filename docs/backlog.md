# Бэклог: приземлённые мысли

Карточки размечает `scripts/prizemlyator.py` из расшифровки голоса, дальше их
чистит человек: склеивает разрезанное, заполняет следующее действие, убирает
пустышки. Правило жёсткое: **цифра с пометкой «нужен скрин» не идёт в ролик,
пока подтверждения нет.**

Тип: **Факт** · **Действие** · **Идея** · **Провал/риск** · **Мысль**.
Статус: `новое` → `в работе` → `снято` / `в ролике №N` / `отложено`.

---
