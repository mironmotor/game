# 555 VPN — дизайн (лендинг + дизайн-система)

Готовый дизайн для VPN-проекта (`555-vpn-vpn-10-000-2`). Полностью автономный:
без внешних CDN, шрифтов и картинок — открывается и работает как есть.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Лендинг целиком: герой, преимущества, **реферальная программа**, тарифы, FAQ, футер. Все стили и скрипт копирования ссылки — внутри файла. |
| `design-system.css` | Те же дизайн-токены и компоненты (кнопки, карточки, поля, статусы) отдельным файлом — подключайте на другие страницы (личный кабинет, оплата). |
| `logo.svg` | Официальный логотип 555 VPN (щит с градиентом). Используйте для favicon, приложения, бота, соцсетей — SVG масштабируется без потерь. |

## Как вставить в локальный проект (через Codex)

1. Скопируйте папку `vpn-design/` в проект, например в
   `555-vpn-vpn-10-000-2/web/` (или туда, откуда сервер раздаёт статику).
2. Отдавайте `index.html` как главную страницу сайта.
3. Для остальных страниц подключайте `design-system.css`:
   `<link rel="stylesheet" href="/design-system.css">` — и используйте классы
   `.btn`, `.card`, `.panel`, `.input`, `.badge`.

## Логотип

Официальный логотип — `logo.svg` (щит «555» с градиентом). На лендинге он
продублирован инлайн-SVG в шапке и герой-блоке (помечено комментарием
`<!-- ЛОГОТИП -->`), чтобы страница оставалась полностью автономной, и
подключён как favicon: `<link rel="icon" type="image/svg+xml" href="logo.svg">`.

## Как перекрасить (если захочется другие цвета)

Все цвета — в `:root` в начале `index.html` и `design-system.css`
(одинаковый блок). Достаточно поменять:

```css
--accent:   #4f8cff;  /* основной цвет логотипа */
--accent-2: #9b5cff;  /* второй цвет градиента */
--accent-3: #35e0d0;  /* акцент статусов */
--bg:       #070b14;  /* фон */
```

## Что поправить под себя

- **Домен рефералки**: в `index.html` найдите `555vpn.example/?ref=VASH-KOD`
  и подставьте ваш реальный домен.
- **Цены тарифов**: секция `#pricing` — сейчас 199 ₽ / 555 ₽ (6 мес, хит) / 999 ₽.
- **Кнопки «Выбрать»**: сейчас `href="#"` — подставьте ссылки на оплату
  (или на бота в Telegram).

## Что нужно от бэкенда для рефералки

Дизайн-блок готов, серверу остаётся:

1. Генерировать уникальный код для каждого пользователя и подставлять его
   в поле ссылки (`input#refLink`) вместо `VASH-KOD`.
2. Ловить параметр `?ref=КОД` при заходе и сохранять его (cookie/сессия)
   до момента оплаты.
3. После оплаты приглашённого — начислить +30 дней обоим.
